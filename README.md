# CalFlow Engineering Calculator

Bilingual TH/EN engineering calculators for conveyor and pneumatic systems.

- Flat-belt drive, gearbox, sprocket, speed, capacity, power, and torque calculations
- Export calculation reports to PDF
- Installable PWA for desktop, Android, iPhone, and iPad
- Public app: https://thanakritposa69-stack.github.io/calflow-engineering/

## Development

```bash
npm install
npm run build
```
